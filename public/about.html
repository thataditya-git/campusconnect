About CampusConnect

A single, accessible place for students to discover and register for events on campus.

Why we built it

Event information on campus is scattered across posters, group chats and notice boards, so students miss out and organizers struggle to gauge interest. CampusConnect brings listings, registration and organizer tools together in one responsive web app.

What it does

🔎 Browse & search

Filter events by category and search by keyword in real time.

📝 One-click registration

Reserve a seat with validated forms and live capacity checks.

📣 Host events

Clubs publish their own events in seconds.

📊 Organizer dashboard

Track registrations and manage listings.

Accessibility

The site is built with semantic HTML5 landmarks, labelled form controls, a skip-to-content link, visible keyboard focus, aria-live status messages and a light/dark theme with WCAG AA colour contrast — so it works for keyboard, screen-reader and mobile-only users.
